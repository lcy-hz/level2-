# 本地 Level-2 连续研究报告

基于本地沪深 A 股 Level-2、日线和分钟线生成交互报告。仅用于研究，不构成交易授权。

## 启动

需要 Python 及 `duckdb`、`pandas`、`pyarrow`。将 `level2_paths.example.json` 复制为同目录 `level2_paths.json`，填写实际绝对路径。配置修改后重启服务。

首次运行需先生成基准报告并构建 Vue 页面（当前服务默认基准日为 20260922，需对应正式数据及提交标识）：

```sh
python generate_level2_report.py
cd frontend && npm ci && npm run build && cd ..
python level2_detail_server.py
```

访问 http://127.0.0.1:18762/ 。Python 服务直接提供构建后的 Vue 页面和本地 API；旧报告 URL 仅重定向到同一 Vue 页面并保留日期或快照参数，不再展示旧 HTML 界面。服务仅监听本机，可选择其他有完整数据的日期生成报告。生成器的默认日期回归断言针对本项目已核验的数据，并非通用任意日期启动器。

单股深查的计算和来源指纹位于 `level2_detail_research.py`，`level2_detail_service.py` 负责按日期读取报告、按需任务及缓存，`level2_detail_server.py` 是本地 HTTP 入口；页面仍只有 Vue 入口。`Workspace` 直接依赖服务层，不反向导入 HTTP 入口。计算代码从原服务文件拆出后，旧深查缓存的代码指纹会一次性失配，需按需重新计算；原缓存文件不删除。此后仅调整 HTTP 路由、任务服务或页面，不会无故使单股深查计算缓存失效；修改研究计算或其依赖仍会失效。

### Vue 3 页面

页面中的日期选择可查看已就绪报告，对满足最近 7 交易日来源门槛的未就绪日期可发起计算并跟踪状态；计算失败保留当前已打开的证据。连续观察默认尝试读取已有的 3 日结果，不因打开页面而发起原始数据扫描；尚无结果时需手动应用窗口。完成的连续结果保存来源身份，服务重启后仅在来源未变时恢复。

新报告保存在 `.level2_reports/<日期>/report.json`，不再生成旧 HTML 页面；正式报告缺少 JSON 时必须重新计算，不回退读取旧 HTML。新快照只生成带完整性校验的 JSON 包；已有 HTML 快照仍可通过数据接口只读解析，原文件不删除，也不会在浏览器中展示旧界面。旧报告书签重定向至统一的 Vue 入口。

新报告的股票记录按代码固定排序；历史快照保持保存时的记录顺序。旧生成器的查询未指定股票顺序，已保存的两个旧快照中重点股首序不同，因此不存在可稳定复现的单一“旧页默认顺序”。默认顺序不是候选强度排名；需要按涨跌幅、主动净额等排序时应明确选择指标。

需要前端开发热更新时，另开终端运行 `cd frontend && npm run dev`，访问 http://127.0.0.1:5173/ 。Vite 只向本机 `127.0.0.1:18762` 代理 `/api`，不直接读取原始 Level-2 文件。

当前 Vue 页面接入 `/api/report/data?date=YYYYMMDD`、`/api/snapshot/data?id=...`、Python 派生的 `/api/state/view` 及按需形态接口，展示质量报告、7 日市场轨迹、连续观察、全库候选筛选、个股证据与独立形态 Tab。候选卡和连续证据卡的代码悬浮读取前复权日 K，“分”读取报告当日分钟 K，均展示成交量；每次实时悬浮重新读取本地文件，不沿用旧缓存。分钟图另展示以昨收为基点、只在有成交分钟收盘价上计算的已观测最大回撤；昨收或成交分钟缺失时未知，旧快照未保存该字段时不补读。它不使用分钟内高低点，缺分钟可能低估实际盘中回撤，也不是连续窗口盘中最大回撤。候选详情可按需计算该股盘中五时段、关联委托与原始委托类型；缓存结果须匹配当日报告与来源身份。形态 Tab 可按需运行 22 类规则、筛选事件和查看逐根前复权 K 证据，但不代表收益优势或交易确认。实时报告必须通过现有来源指纹门槛；Vue 快照冻结当前页面已加载的报告、连续窗口、图表、深查、形态结果与已查看的形态详情，以及候选和连续观察的筛选排序展示状态；未保存的证据明确不可用，不拿最新数据填充。旧快照缺少连续展示状态时按默认控件呈现。开发验证：`cd frontend && npm test && npm run build`。

历史 HTML 快照仍可从统一 Vue 页面只读打开，但不恢复旧页面：其候选筛选值“全部”在展示层映射为 `all`，旧 `sortOrder` 映射为 `sortDirection`，原快照包不改写；同一证据日切换不同快照时，各面板按已加载快照身份重新初始化，不能沿用上一份快照的筛选、图表弹窗或证据状态。候选卡保留独立的上涨／下跌／平盘方向标记；方向缺失时显示未知，不借涨跌幅推定。点击候选卡非控件区域也能打开证据，图表按钮保持独立，“查看证据”按钮供键盘操作。窄屏候选区在约 540–620px 宽度保持双列，更窄时单列；这仅校准已知局部截图，不等于整页逐像素验收。

按需单股深查现额外读取已提交的当日 `snapshot`，按五时段展示有效买卖一档中间价的首末变化和低点至末值恢复，并列快照覆盖与主动净额；可展开查看价差中位数（bp）、一档与十档显示量差中位数及相邻有效快照的同价买一显示量上升次数／可比对数。价差＝(卖一－买一)÷中间价，量差＝(买量－卖量)÷两侧总量；十档须全部价量有效、买档价格严格递减且卖档严格递增，按两侧各十档显示量合计计算，单独列出十档覆盖。它是静态十档量差，不是距离加权深度或另一份独立证据。无有效报价／深度不补零，无同价可比对数不写成 0% 补单率。来源身份纳入快照文件。它不重建订单队列，不证明补单、被动吸筹或因果价格冲击。旧快照缺字段时显示未保存，绝不补读最新盘口。

## 功能与边界

- 全市场日级扫描、候选筛选排序、个股按需深查。
- 目标日三表质量报告：证券交并集与缺少清单、日期/时钟计数、未知方向金额、成交候选键重复、连续竞价同股同时间快照重复、三表全字段完全重复、三表 Parquet 物理行时钟回退及两种委托字段的匹配核验。快照全字段重复先圈出同股同日期同时间候选，再逐字段精确分组；成交与原始委托按股票分批对全部原始字段分组。物理行时间回退仅描述文件排列，不等于交易所源事件乱序。各自显示分母，不自动去重；按需盘口路径遇重复时间拒绝任意选样。原始文件只读；详细SQL及可重跑入口见 `Level2数据质量核验.ipynb`。
- 原报告、按需深查和连续状态统一未知方向降级：未知不填零。无效关联编号单列，不拼成大单；缺频道与订单事件语义，因此编号分组仍不等于机构母单。
- 本地日K／分钟K及成交量；本地最新读取不是交易所实时行情。
- 连续窗口按已提交的主目录分钟文件逐日汇总有成交分钟收盘价，用逐日 `adj_factor` 调整后与窗口前一交易日复权收盘合成“已观测分钟收盘最大回撤”；逐日摘要按来源身份缓存，窗口缺日、异常分钟、缺因子或缺基点均不跨越／补零。结果随连续状态来源凭据和快照冻结，显示峰谷分钟、成交分钟覆盖和来源就绪天数，支持独立排序。它不是分钟内高低点或可成交路径的最大回撤；缺分钟可能低估真实盘中风险。
- 日K与形态使用 `stk_factor_pro_by_code`（例如 `000977_SZ_stk_factor_pro.csv`）中的qfq价格／指标，不依赖adj_factor、不回退by_date，截断至报告日；原by_date配置继续用于既有连续状态。形态Tab支持22类研究规则、筛选、逐事件标注与逐根K线量价／指标详情，尚未验证收益优势。
- 日期报告与只读快照；仅冻结已加载的图表。
- 连续观察支持按已核验日历切换前／后一交易日、按1个交易日增减窗口、输入天数及3／5／20日快捷选择；未就绪相邻日只选中并提示，不将旧报告冒充新日期。展示净额比水平、日变化、金额加权窗口水平、斜率和持续性，成交额与复权价格独立显示覆盖。Vue 个股逐日证据支持资金变化、连续性、方向覆盖、组合预设、资金方向转换、金额／净额比／价格区间及持续次数筛选，以及净额比、变化、斜率、持续性、成交额和价格等独立排序；未知值不通过数值筛选、排序始终排最后，同值按代码稳定排序。单日窗口的全市场结构变化不适用，但个股在窗口外前一交易日有效时仍可显示并排序较前日变化。排序只改变展示，不构成选股绩效。
- 连续观察的日级事件层只识别相邻有效交易日的净额比负值收敛／扩大、净卖转净买、净买转净卖；记录首次可识别日、证据、后续失效／结束／未知状态。负值收敛仅指净额比变化，不证明绝对卖出额下降、被动吸筹或盘口守位。旧快照未保存此层时不补读。按需单股深查另计算报告日连续竞价逐笔有效成交价路径回撤：成交编号和时间顺序不可靠时保持未知；只描述成交价，不等于可成交的策略回撤。
- 按需单股盘口深查增加微价格相对中间价偏离和距离加权十档显示量差，各五时段列出中位数及有效覆盖；十档缺档或档位价格无序时保持未知。距离权重以当时价差为尺度，属于未校准的描述指标，不等于可成交深度或补单证据。
- 同一深查另列买一、卖一同价显示量下降后首次观测恢复的次数和耗时，报价变化／缺量／时段边界记为删失；无完整恢复不填零。该时间受快照频率及大量删失事件影响，不是订单级补单速度。
- 同一深查现按个股审计 `委托编号`、`交易所委托号` 两个候选字段：有效正编号委托行、候选键、重复／多代码键组、与有效主动成交编号的字段交集，以及 `委托代码` 同字母和单条键同字母计数。单条候选键另列有效时钟下原始记录时间早于／等于／晚于成交的条数与可比分母；同刻不能证明先后，较早也不能证明订单身份。原始字段缺失、无有效编号和时钟不可比分开显示；旧快照未保存时不回填。不据此识别新增、撤单、补单或吸筹。
- 深查可展开查看成交方向与相邻盘口中间价的描述性共变：仅连续竞价相邻有效快照≤10秒、端点之间方向完整且净额非零的成交，排除同刻端点；报告同区间及下一快照方向对齐中间价变化的均值／中位数、同向占比及各类覆盖。14:57后的收盘集合竞价不纳入。它不是因果价格冲击、永久冲击或交易预测；旧快照缺字段不回填。
- 独立的 `level2_validation.py` 可对上述四类日级事件做 1／3／5 交易日收盘到收盘后续收益研究：明确训练截止、最长预测期限隔离区、样本外事件、未到期和缺价格；对照为同日可比较股票等权收益。Vue“后续验证”页签按需运行，展示汇总及按股票检索的逐日事件／后续证据；已加载汇总与实际打开过的逐股明细可凭来源校验后随当前证据快照冻结，旧快照不补读。它不接入实时排序，不能当作可成交收益或信号有效性证明。
- 原报告与连续状态均依赖本地 SSE 交易日历，拒绝日历缺日/重复，不跳过缺数据的交易日。快照仅冻结已计算并加载的窗口，不补读新数据。
- 连续观察的个股成交活跃度按“最新日成交额 ÷ 应用窗口内此前 `N-1` 日均额－1”展示并可排序；仅 `N≥2` 且这 `N` 天成交额全部有效时计算，单日、缺日或旧快照不补零。该指标不是历史成交分位，也不证明吸筹。
- 可在研究配置中设置 `daily_basic_root` 为逐日 `daily_basic` CSV 目录。连续观察按目标日总市值（万元）和 Level-2 成交额分别等数量分组，展示方向可靠股票的主动净额比组内百分位、有效同组数量与来源覆盖；组内不足20只不排名，缺来源、缺市值或未知方向不补零。分组只供收盘后横截面比较，成交额本身受当日交易影响；不是行业中性、盘中可用信号或策略绩效。
- Vue 原候选栏已与当前已应用的同日连续窗口联动：保留原类型／价格筛选，增加资金变化、连续性与连续指标正倒序；卡片最多补两行日级证据，详情顶部列出资金／成交额／价格水平、变化、窗口趋势、持续性、质量和反证。未应用窗口或快照未冻结窗口时不读取最新状态补齐。市场共同方向样本现逐日展示净额比／净买入占比、相邻日变化、窗口斜率与可观察持续性，并逐日标明来源状态和源文件；每日方向覆盖、共同样本分母和全市场成交额分开。另以独立的共同价格样本展示逐日上涨／下跌／平盘占比、上涨宽度变化与斜率，并标明价格有效数及因子文件；价格基于逐日 close×adj_factor 与前一交易日之比，历史当时可得性未验证。两套样本分母可能不同，不把价格宽度当资金扩散。个股已按窗口前一日及窗口内逐日复权收盘计算最大收盘回撤和峰谷日期，并支持排序；不等于盘中最大回撤。基准可在研究配置中指定，目前本机选用沪深300价格指数；仅在指数窗口每日收盘完整时展示个股收益与指数点位收益的百分点差，并可排序，指数不含分红再投资且非所有股票的风格匹配基准。原报告只要存在方向未知股票，便将全市场净额标为未知；共同样本净额排除了这些股票，即使可计算，也不能冒充原报告的全市场净额。不同来源校准结果不得混用。盘中守位／补单事件、行业／风格匹配对照、分钟内真实最大回撤和含成交约束的策略验证尚未实现。连续状态不是吸筹确认或买卖指令。

## 历史来源与连续观察

将 `level2_research.example.json` 复制为 `level2_research.json`，设置 `history_roots`、`trade_calendar`、`default_window`、`max_window`（默认60）及可选的 `benchmark`（指数代码、名称、绝对 CSV 路径）。历史根目录应直接包含 `deal_YYYYMMDD.parquet`。当前本机补充来源是 `/Volumes/990pro/data/level2`。

读取优先级：主数据目录优先，历史目录补缺，同日不叠加。中文原生格式要求正式提交标识；已校准 `/Volumes/990pro/data/level2` 英文旧格式：价格除以100，Side=0主动买、Side=1主动卖，并逐条验证正数买卖编号的先后关系。未知来源、缺编号或方向冲突记录仍为未知，不强行归类。校准证据见 `Level2方向校准说明.md`。`/Volumes/990pro/data/history` 的按月个股文件尚未接入，不能据此视为已校准。

连续观察按需扫描原始成交并缓存日级汇总；首次长窗口可能较慢。来源指纹变化后重新计算。复权价格使用本地 `close×adj_factor` 的比值，历史当时可得性未验证。缺失不填零、不缩短窗口冒充完整。

### 事件后续收益研究

示例（全部日期必须是已核验交易日；不自动搜索最优分割点）：

```sh
python level2_validation.py --start 20260907 --end 20260918 --asof 20260923 --split 20260915 --horizons 1,3,5
```

脚本复用日级聚合缓存与已校准来源，只在相邻两交易日方向均有效时形成事件；缺档不跨越。训练事件的**最长**预测期限若跨训练截止日，统一归入隔离区；样本外从训练截止日后的交易日开始。统计日收盘到未来第 N 个交易日收盘，事件本身仅在触发日日级文件就绪后已知，因此这里不是可执行的入场回测。输出中的未到期、价格缺失和缺 Level-2 日期各自分列，不补零。新增次日日线必要门槛，独立标出未到期、缺日线／缺价、价关系异常、量未知／零量、单一价位，以及仅可作价格参考的样本；即使通过最后一档也不证明有实际订单或排队成交，旧快照缺门槛不回填。涨停专项另展示次日开盘跳空价格参考，并在后3／5日列出同样本的信号收盘至终点收盘与次日开盘至终点收盘变化；后1日不把次日开盘至当日收盘写成普通A股可执行路径。开盘参考仅取有成交量且OHLC有效的日线，复权口径为当日 `raw_open × adjusted_close / raw_close`；它不是开盘可成交价，旧快照不回填。另按触发日至目标日每天有效的复权收盘计算已观测最大收盘回撤及峰谷日期；路径缺价不以端点收益补齐，汇总显示完整路径覆盖数。它不是盘中或真实成交后的策略回撤。复权因子的历史当时可得性、涨跌停成交、费用、滑点、容量及行业／风格控制仍未验收；只能作为描述性检验，不能据此升级为有效策略。`--details` 可输出全部逐股观察；服务端以 SQLite 索引存放逐股结果，不因页面查一只股票而重扫原始 Level-2，文件摘要与研究来源均须匹配。页面支持手动设置训练／事件／数据日期，仅冻结已完成、来源未变化的研究摘要及已打开的最多50只逐股证据；服务重启后未保存的任务需重新提交。页面只展示由 `close×adj_factor` 比值得出的收益，不把其绝对计算值当作可成交股价。

后续验证页可按分段、期限和事件类型展开逐触发日核对，分别显示当日触发／成熟／未到期／缺价数、事件平均收益、同日基准和平均超额；触发日与已观察日分列，未到期日不把基准覆盖写成零，跨日等权数只使用有成熟可比结果的日期。逐日汇总随来源凭据和新快照冻结，旧快照没有此字段时不读取最新数据补齐。同日股票相关、期限重叠与样本外日期不足仍可能使均值不稳，页面不据此输出显著性或交易结论。

逐日核对现补充“逐日剔一”敏感性：仅当至少两个事件日有可比较超额时，分别剔除一个事件日、重新计算其余日期的等权超额，并展示所得最小／最大值及是否跨零。此范围衡量单个日期对描述均值的影响，不是置信区间、显著性检验或策略稳定性证明；一个可比较日时明确不适用。旧快照缺字段不回填。

同一“后续验证”计算另包含独立的**涨停收盘股四格研究**，不更换 Vue 页面或基本事件汇总。母样本来自本地 `limit_list_d/by_date/YYYYMMDD_limit_list_d.csv` 的 `limit=U`，只留非 ST 沪深 A 股；炸板 `Z`、跌停 `D`、北交所和 ST 不混入。涨停列表当日收盘与 `stk_factor_pro` 原始收盘核对，缺复权因子／价格的记录不可计算收益。市场变量是在排除当日 U 股后、相邻日共同方向有效股票上的成交额加权主动净额比变化；个股变量是自身净额比变化。两者的正／负方向预先固定为四格，不按结果选阈值；未知、平值、缺档、跨来源单列。结果按训练／隔离／样本外和1／3／5交易日显示样本数、后续收盘收益、相对同日 U 股均值的按日等权超额、逐日剔一范围，以及同日“个股改善组−恶化组”的配对收益差。配对仅控制同一事件日，市场改善与恶化仍是跨日比较，不能解释为因果、买卖点或成交收益。涨停名单和复权因子的历史首次可得性未核验。

涨停专项另提供**同日同板块对照**：沪深主板、创业板、科创板分别以同日 U 股有效价格池作基准，并只在同日同板块内“改善／恶化”两组均有后续价时配对；各板块先在当日等权，再按事件日等权，逐日剔一仍按交易日而非股票或板块日。缺组保持不可比，不将跨板块构成差异当作资金因子。此对照仍未控制行业、市值、封板质量、成交容量及执行成本。

同一 Vue“后续验证”折叠区现补充极值与容量诊断，不另生成页面：原同板块收益均值差旁边列出逐日收益差中位数、板块内两组个股收益中位数之差的按日等权均值，以及每侧至少 3 只有价股票时的固定门槛对照；门槛不满足显示不可比，不用筛选后的结果替换原结果。四格另显示触发日 Level‑2 成交额中位数与次日日线门槛分布。成交额只反映当日已成交金额，次日日线门槛只排除部分明显不可观察或单一价位情形，均不刻画可下单容量、涨停队列、实际成交概率或交易成本。旧快照缺这些字段时保持未知，不读取新数据补齐。

同页还可展开同板块对照的逐交易日影响表：逐日保存进入配对的板块、改善／恶化两侧样本、当日均值差和个股中位差；剔除当日后以其余事件日等权重算总均值，并列出该日对原均值的百分点影响。只有一个配对日时剔除值未知，不造零；旧快照缺逐日板块明细时仍可看其已保存的原日期差值，但不从当前文件补样本。

默认涨停名单目录从已配置的 `stk_factor_pro/by_date` 同一股票同步树推导；不同目录可复制 `level2_limitup_sources.example.json` 为本地 `level2_limitup_sources.json` 并设置 `limit_list_d_root` 绝对路径。该本地文件不入库，但其配置及逐日涨停文件、研究代码都进入后续研究来源身份；旧研究凭据或快照缺专项字段时不使用新数据补齐。

逐日表还显示前日与触发日的 Level‑2 来源。新计算只在相邻两交易日都属于同一种已核验来源时形成事件；缺档、跨来源和未知来源不跨越，分别记录缺档日与来源排除日。页面单列排除日期与数量；旧研究快照不回填排除记录，需重算才可按当前口径比较。研究窗口同时含已校准旧格式和正式新格式时仍显示来源混合警示，并以可比较触发日为单位展示描述性来源分层均值。来源与历史时期高度相关，分层差异不能归因于格式，也不据此视为跨来源口径已完全可比。

新研究结果另外冻结所有所需 Level‑2 与复权日线文件的本地最后修改时间审计，并在正文标明存在、缺档及“最后修改日期晚于交易日”的数量和明细。修改时间不是首次发布／首次可得时间；复制和回填均可能改变它。即使没有晚修改记录，也不能证明历史 PIT。旧快照缺此审计时不读取当前文件补齐；页面的“样本外”仅指按交易日期切分，严格 PIT、成交与成本仍未验收。

报告来源门槛只比较报告生成所需的交易日历、原始文件、配置和生成代码；连续状态计算代码单独纳入连续结果来源身份。旧报告来源记录若仍包含 `level2_state.py`，仅允许这一文件指纹变化，其他输入及记录本身仍须一致，避免事件展示改动无故迫使全量报告重算。

原始行情、本机配置、缓存、生成报告、快照及其他研究文件不纳入仓库。首次克隆不会附带可直接浏览的业务数据。
