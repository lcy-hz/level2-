# 本地 Level-2 连续研究报告

基于本地沪深 A 股 Level-2、日线和分钟线生成交互报告。仅用于研究，不构成交易授权。

## 启动

需要 Python 及 `duckdb`、`pandas`、`pyarrow`。将 `level2_paths.example.json` 复制为同目录 `level2_paths.json`，填写实际绝对路径。配置修改后重启服务。

首次运行需先生成基准报告（当前服务默认基准日为 20260922，需对应正式数据及提交标识）：

```sh
python generate_level2_report.py
python level2_detail_server.py
```

访问 http://127.0.0.1:18762/level2-market-scan_20260922.html 。服务仅监听本机，可选择其他有完整数据的日期生成报告。生成器的默认日期回归断言针对本项目已核验的数据，并非通用任意日期启动器。

### Vue 3 页面（逐项迁移中）

另开终端运行 `cd frontend && npm ci && npm run dev`，访问 http://127.0.0.1:5173/ 。先启动上面的 Python 服务；Vite 只向本机 `127.0.0.1:18762` 代理 `/api`，不直接读取原始 Level-2 文件。

当前 Vue 页面接入 `/api/report/data?date=YYYYMMDD`、`/api/snapshot/data?id=...`、Python 派生的 `/api/state/view` 及按需形态接口，展示质量报告、7 日市场轨迹、连续观察、全库候选筛选、个股证据与独立形态 Tab。候选卡和连续证据卡的代码悬浮读取前复权日 K，“分”读取报告当日分钟 K，均展示成交量；每次实时悬浮重新读取本地文件，不沿用旧缓存。候选详情可按需计算该股盘中五时段、关联委托与原始委托类型；缓存结果须匹配当日报告与来源身份。形态 Tab 可按需运行 22 类规则、筛选事件和查看逐根前复权 K 证据，但不代表收益优势或交易确认。实时报告必须通过现有来源指纹门槛；Vue 快照只冻结当前页面已加载的报告、连续窗口、图表、深查、形态结果与已查看的形态详情，未保存部分明确不可用，不拿最新数据填充。开发验证：`cd frontend && npm test && npm run build`。

## 功能与边界

- 全市场日级扫描、候选筛选排序、个股按需深查。
- 目标日三表质量报告：证券交并集与缺少清单、日期/时钟计数、未知方向金额、成交候选键重复和两种委托字段的匹配核验。按证券分块，原始文件只读；详细SQL及可重跑入口见 `Level2数据质量核验.ipynb`。
- 原报告、按需深查和连续状态统一未知方向降级：未知不填零。无效关联编号单列，不拼成大单；缺频道与订单事件语义，因此编号分组仍不等于机构母单。
- 本地日K／分钟K及成交量；本地最新读取不是交易所实时行情。
- 日K与形态使用 `stk_factor_pro_by_code`（例如 `000977_SZ_stk_factor_pro.csv`）中的qfq价格／指标，不依赖adj_factor、不回退by_date，截断至报告日；原by_date配置继续用于既有连续状态。形态Tab支持22类研究规则、筛选、逐事件标注与逐根K线量价／指标详情，尚未验证收益优势。
- 日期报告与只读快照；仅冻结已加载的图表。
- 连续观察支持按1个交易日增减窗口、输入天数及3／5／20日快捷选择；展示净额比水平、日变化、金额加权窗口水平、斜率和持续性，成交额与复权价格独立显示覆盖。Vue 个股逐日证据支持资金变化、连续性、方向覆盖筛选，以及净额比、变化、斜率、持续性、成交额和价格等独立排序；未知值始终排最后，同值按代码稳定排序。单日窗口的全市场结构变化不适用，但个股在窗口外前一交易日有效时仍可显示并排序较前日变化。排序只改变展示，不构成选股绩效。
- 连续观察的日级事件层只识别相邻有效交易日的净额比负值收敛／扩大、净卖转净买、净买转净卖；记录首次可识别日、证据、后续失效／结束／未知状态。负值收敛仅指净额比变化，不证明绝对卖出额下降、被动吸筹或盘口守位。旧快照未保存此层时不补读。
- 独立的 `level2_validation.py` 可对上述四类日级事件做 1／3／5 交易日收盘到收盘后续收益研究：明确训练截止、最长预测期限隔离区、样本外事件、未到期和缺价格；对照为同日可比较股票等权收益。Vue“后续验证”页签按需运行，展示汇总及按股票检索的逐日事件／后续证据；已加载汇总与实际打开过的逐股明细可凭来源校验后随当前证据快照冻结，旧快照不补读。它不接入实时排序，不能当作可成交收益或信号有效性证明。
- 原报告与连续状态均依赖本地 SSE 交易日历，拒绝日历缺日/重复，不跳过缺数据的交易日。快照仅冻结已计算并加载的窗口，不补读新数据。
- Vue 原候选栏已与当前已应用的同日连续窗口联动：保留原类型／价格筛选，增加资金变化、连续性与连续指标正倒序；卡片最多补两行日级证据，详情顶部列出资金／成交额／价格水平、变化、窗口趋势、持续性、质量和反证。未应用窗口或快照未冻结窗口时不读取最新状态补齐。市场共同方向样本现逐日展示净额比／净买入占比、相邻日变化、窗口斜率与可观察持续性，并逐日标明来源状态和源文件；每日方向覆盖、共同样本分母和全市场成交额分开。另以独立的共同价格样本展示逐日上涨／下跌／平盘占比、上涨宽度变化与斜率，并标明价格有效数及因子文件；价格基于逐日 close×adj_factor 与前一交易日之比，历史当时可得性未验证。两套样本分母可能不同，不把价格宽度当资金扩散。个股已按窗口前一日及窗口内逐日复权收盘计算最大收盘回撤和峰谷日期，并支持排序；不等于盘中最大回撤。原报告只要存在方向未知股票，便将全市场净额标为未知；共同样本净额排除了这些股票，即使可计算，也不能冒充原报告的全市场净额。不同来源校准结果不得混用。盘中守位／补单事件、行业／风格匹配对照、盘中回撤和含成交约束的策略验证尚未实现。连续状态不是吸筹确认或买卖指令。

## 历史来源与连续观察

将 `level2_research.example.json` 复制为 `level2_research.json`，设置 `history_roots`、`trade_calendar`、`default_window` 和 `max_window`（默认60）。历史根目录应直接包含 `deal_YYYYMMDD.parquet`。当前本机补充来源是 `/Volumes/990pro/data/level2`。

读取优先级：主数据目录优先，历史目录补缺，同日不叠加。中文原生格式要求正式提交标识；已校准 `/Volumes/990pro/data/level2` 英文旧格式：价格除以100，Side=0主动买、Side=1主动卖，并逐条验证正数买卖编号的先后关系。未知来源、缺编号或方向冲突记录仍为未知，不强行归类。校准证据见 `Level2方向校准说明.md`。`/Volumes/990pro/data/history` 的按月个股文件尚未接入，不能据此视为已校准。

连续观察按需扫描原始成交并缓存日级汇总；首次长窗口可能较慢。来源指纹变化后重新计算。复权价格使用本地 `close×adj_factor` 的比值，历史当时可得性未验证。缺失不填零、不缩短窗口冒充完整。

### 事件后续收益研究

示例（全部日期必须是已核验交易日；不自动搜索最优分割点）：

```sh
python level2_validation.py --start 20260907 --end 20260918 --asof 20260923 --split 20260915 --horizons 1,3,5
```

脚本复用日级聚合缓存与已校准来源，只在相邻两交易日方向均有效时形成事件；缺档不跨越。训练事件的**最长**预测期限若跨训练截止日，统一归入隔离区；样本外从训练截止日后的交易日开始。统计日收盘到未来第 N 个交易日收盘，事件本身仅在触发日日级文件就绪后已知，因此这里不是可执行的入场回测。输出中的未到期、价格缺失和缺 Level-2 日期各自分列，不补零。复权因子的历史当时可得性、涨跌停成交、费用、滑点、容量及行业／风格控制仍未验收；只能作为描述性检验，不能据此升级为有效策略。`--details` 可输出全部逐股观察；服务端以 SQLite 索引存放逐股结果，不因页面查一只股票而重扫原始 Level-2，文件摘要与研究来源均须匹配。页面支持手动设置训练／事件／数据日期，仅冻结已完成、来源未变化的研究摘要及已打开的最多50只逐股证据；服务重启后未保存的任务需重新提交。页面只展示由 `close×adj_factor` 比值得出的收益，不把其绝对计算值当作可成交股价。

报告来源门槛只比较报告生成所需的交易日历、原始文件、配置和生成代码；连续状态计算代码单独纳入连续结果来源身份。旧报告来源记录若仍包含 `level2_state.py`，仅允许这一文件指纹变化，其他输入及记录本身仍须一致，避免事件展示改动无故迫使全量报告重算。

原始行情、本机配置、缓存、生成报告、快照及其他研究文件不纳入仓库。首次克隆不会附带可直接浏览的业务数据。

## 验证

形态计算的by_code CSV读取采用最多8线程；界面显示完成数／总数。读取结果按代码固定排序，继续保留窗口截断、冲突行与来源变化校验。形态识别阶段仍为单任务计算，并发读取不代表整个流程加速8倍。

```sh
python -m unittest discover -p 'test_level2*.py'
python validate_level2_report.py
node test_level2_pattern_chart.js
```

测试前需建立本机路径配置；报告校验还要求先生成基准报告。

质量报告不等于完整性认证：逐字段完全重复行、事件乱序、撤单/补单类型和队列重建仍未完成。候选键重复可能是频道或多事件问题，不自动去重；盘后记录可能是延迟发布，不作可交易盘口。
